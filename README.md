— exactly one letter, A for coffee or B for tea, and nothing else.

## The letter

> A

A for coffee: the first cup of the day, dark, strong, and impossible to
ignore — the drink that turns "not yet awake" into "let's go".

## How it works

`main.py` (pure Python 3.13 stdlib, no network, deterministic) writes exactly
that one letter to `/output/entry.txt`.

```sh
python3 main.py
```
